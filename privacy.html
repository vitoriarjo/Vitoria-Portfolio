Privacidade

Como os dados de navegação são usados neste portfólio.

Este site utiliza ferramentas de analytics para entender, de forma agregada, como o portfólio é navegado e quais conteúdos ajudam mais quem o visita.

FinalidadeMelhorar conteúdo, navegação e experiência
FerramentasPostHog e Microsoft Clarity
PostHog

Eventos e funil

É usado para medir visualizações de páginas e interações como abertura de cases, acesso ao CV, LinkedIn e canais de contato. Os eventos customizados deste portfólio não são configurados para enviar nome, e-mail ou telefone.

Microsoft Clarity

Comportamento de navegação

É usado para compreender padrões de clique, rolagem e navegação por meio de heatmaps e gravações de sessão, ajudando a identificar pontos de fricção ou conteúdo pouco percebido.

Contato

Links externos

Ao abrir LinkedIn, WhatsApp, e-mail ou outros serviços externos, passam a valer também as políticas e configurações desses serviços.

Escopo

Uso do portfólio

Os dados de navegação são utilizados para avaliar e melhorar este portfólio profissional. Esta página de privacidade não carrega as ferramentas de analytics descritas acima.
